# Эксплуатация и передача проекта

## Файлы данных

Основные файлы находятся в `plugins/Duels/`:

| Файл/каталог | Содержимое |
| --- | --- |
| `config.yml` | общие параметры, турниры, NPC, голограммы, лимиты регена |
| `lang.yml` | сообщения плагина |
| `commands.yml` | настройки команд |
| `tournaments.yml` | турниры, участники, сетки, матчи и результаты |
| `tournament-lobby.json` | точка турнирного лобби |
| `arena-recovery.yml` | аварийный снимок разрушаемых арен |
| данные арен и китов | точки, bounds, предметы и настройки китов |

Перед обновлением остановите сервер и создайте резервную копию всего каталога.
Не редактируйте `tournaments.yml` и `arena-recovery.yml` во время работы Paper.

## Безопасное обновление

1. Запретите запуск новых матчей.
2. Дождитесь завершения активных боёв и состояния `READY` у разрушаемых арен.
3. Остановите Paper штатной командой `stop`.
4. Скопируйте `plugins/Duels/` в резервную папку.
5. Замените JAR и запустите сервер.
6. Проверьте загрузку Duels, число арен/китов и `tournaments.yml`.
7. Проведите тестовую Sword-дуэль и тест разрушаемой арены.

## Проверка восстановления

```text
/duels arena restorestatus <arena>
/duels arena debug <arena>
```

Во время `RESTORING` не запускайте новый матч на этой арене. Если автоматическое
восстановление остановилось, сохраните логи и recovery-файл, затем используйте
`/duels arena restore <arena>`. Не удаляйте recovery-файл до выяснения причины.

## Диагностика турниров

```text
/tour info <турнир>
/tour mymatch
/tour npc list
/tour holo list
```

Если NPC не открывает меню, проверьте наличие и загрузку FancyNpcs, точное имя/ID
в `/tour npc list` и `tournament.fancy-npcs.enabled`. Если головы недоступны,
меню использует стандартные материалы; HeadDB не является обязательным.

## Откат

1. Остановите сервер.
2. Верните предыдущий JAR.
3. Восстановите резервную копию `plugins/Duels/`, созданную перед обновлением.
4. Запустите Paper и проверьте консоль.

Откат только JAR без соответствующих данных допустим лишь при гарантированной
совместимости формата. Для передачи другому администратору передавайте исходники,
собранный JAR, резервную копию данных и эту документацию.
